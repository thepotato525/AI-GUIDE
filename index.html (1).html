Fundamentals

AI를 내 비서로 만드는 핵심 원칙

AI는 마법이 아닌 도구입니다. 정확하게 지시하고 원리를 이해해야 100% 활용할 수 있습니다.

효과적인 프롬프트 작성법

질문이 구체적일수록 답변도 정교해집니다. 'CREATE' 공식을 기억하세요.

  • C (Context): 배경 상황 설명하기
  • R (Role): AI에게 역할 부여하기 (예: "너는 마케터야")
  • E (Explanation): 명확한 목적 설명
  • F (Format): 출력 형태 지정 (표, 글머리기호 등)

할루시네이션(환각) 주의

AI는 때때로 그럴듯한 거짓말을 합니다. 이를 '할루시네이션'이라고 부릅니다.

예방 및 대처법:

  • 사실 확인(Fact-check)은 필수
  • "정보의 출처를 함께 제시해줘"라고 요청
  • 최신 정보가 필요한 경우 검색 기능이 있는 AI 사용 (Perplexity 등)

AI의 작동 원리 이해

LLM(거대 언어 모델)은 기본적으로 '다음 단어 예측기'입니다.

입력된 문맥을 바탕으로 확률적으로 가장 적절한 다음 단어를 생성해냅니다. 사람처럼 '생각'하는 것이 아니라 방대한 데이터 패턴을 매칭하는 것이므로, 원하는 패턴(예시 데이터)을 프롬프트에 포함시켜주면 결과물의 품질이 급격히 상승합니다.

프롬프트 퀄리티 비교 (Before & After)

아쉬운 프롬프트 (추상적)

"다이어트 식단 좀 짜줘"

결과: 닭가슴살, 고구마 등 누구나 아는 일반적인 내용만 나열되며, 질문자의 현재 상황(나이, 예산, 알레르기 등)이 전혀 반영되지 않은 무용지물 답변이 나옵니다.

훌륭한 프롬프트 (구체적)

"나는 30대 직장인이고, 한 달에 2kg 감량이 목표야. 점심은 회사 구내식당을 이용하고 저녁만 직접 요리해. 해산물 알레르기가 있으니 제외하고, 1주일치 저녁 식단표를 마크다운 표 형태로 만들어줘."

결과: 알레르기 정보, 식사 가능 환경, 원하는 출력 형태(표)까지 모두 반영된 완벽한 맞춤형 식단표를 얻을 수 있습니다.

초간단 Vercel 배포 방법 (3-Step)

  1. GitHub 업로드: 작성된 코드(HTML/JS 또는 React 등)를 본인의 GitHub Repository에 Commit하고 Push 합니다.
  2. Vercel과 연동: Vercel.com에 로그인 후 'Add New Project'를 눌러 방금 업로드한 Repository를 Import(가져오기) 합니다.
  3. Deploy (배포) 실행: 프레임워크 설정을 확인하고 'Deploy' 버튼을 누르면 배포가 완료됩니다.

Netlify 드래그 앤 드롭 배포 (3-Step)

  1. 파일 준비: AI가 만들어준 단일 `index.html` 파일을 하나의 폴더 안에 넣습니다.
  2. Netlify 로그인: Netlify 사이트에 가입/로그인 후 'Sites' 메뉴로 이동합니다.
  3. 폴더 드래그: 하단의 "Drag and drop your site output folder here" 영역에 준비한 폴더를 끌어다 놓으면 즉시 배포됩니다.

Cloudflare Pages 배포 방법 (3-Step)

  1. 대시보드 접속: Cloudflare 가입 후 대시보드 좌측 메뉴에서 'Workers & Pages'를 클릭합니다.
  2. 프로젝트 생성: 'Create application' -> 'Pages' 탭을 선택하고 'Connect to Git' (GitHub 연동) 또는 'Direct Upload' (직접 업로드)를 선택합니다.
  3. 배포 완료: 저장소를 선택하거나 폴더를 업로드한 후 'Save and Deploy'를 클릭하면 전 세계 엣지 네트워크를 통해 초고속으로 배포됩니다.
